## Product language

Minerva Console and other Minerva internal systems are English-first. Keep all
visible product UI copy in English unless a request explicitly requires another
language. This applies to labels, buttons, helper text, placeholders, filters,
badges, empty states, messages, workflow actions, and internal report controls.
Do not rename database values, API contracts, or backend enums to enforce this
rule.
