## Summary

Implemented a scoped context-pack exporter for Minerva Core Brain using a new
zero-dependency sibling script. The legacy monolithic exporter remains
available and unchanged in behavior through `npm run brain:export-context`.

## Exporter design choice

Created `scripts/brain-export-context-packs.mjs` instead of extending
`scripts/brain-export-context.mjs`.

Reason: the original exporter is stable, simple, and load-bearing for the
existing `content/brain/exports/brain-context.md` handoff. A sibling script
keeps backwards compatibility intact while adding scoped pack recipes and CLI
flags independently.

## Local pack cap behavior

The local pack generator applies a deterministic hard cap of 25,000 characters.
This run produced `content/brain/exports/packs/local-MCB-0023.md` at 23,299
characters, so no truncation marker was needed. If the rendered pack exceeds
the limit, it truncates at the previous source boundary when possible and
appends:

```text
[TRUNCATED: local pack size cap reached]
```
