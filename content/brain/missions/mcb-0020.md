# MCB-0020 - Scoped Context Pack Exporter

## Status

Completed.

## Summary

Adds deterministic, zero-dependency scoped context packs for Minerva Core Brain
so future agents can use focused handoff files instead of the full monolithic
`content/brain/exports/brain-context.md` every time. The existing full export
remains available through the legacy exporter, while the new sibling pack
exporter writes `full`, `mission`, `agent`, `project`, `review`, and `local`
packs under `content/brain/exports/packs/`.

## Scope

- Add a sibling scoped context-pack exporter under `scripts/`.
- Add npm scripts for the legacy full export and scoped pack generation.
- Generate deterministic Markdown packs under `content/brain/exports/packs/`.
- Add short exports documentation.
- Self-register MCB-0020 in the mission ledger and update roadmap, changelog,
  and agent report.
