# ENTRY — Public Registration Branding Simplification

**Status:** Captured / pending implementation  
**Priority:** P0 / Pre-launch polish  
**Date:** 2026-09-04  
**Product:** ENTRY  
**Area:** Public Registration Link / Onboarding UX / Branding

## Mission objective

Simplify the public user-registration link so ENTRY's registration content keeps visual priority.

Current issue: the public registration page has a large black top area/header with `Minerva Technologies`. It consumes too much vertical space and competes with the actual registration task.

## Product decision

Remove the large top branding block/header.

Replace it with a **very discreet Minerva Technologies attribution near the bottom of the page**, so the brand remains present without taking protagonism away from:

- community context,
- registration instructions,
- form fields,
- activation/onboarding actions,
- success/error states.

## Visual direction

The public page should feel:

- focused,
- lightweight,
- mobile-first,
- trustworthy,
- clearly ENTRY/community oriented.

Minerva branding should behave like quiet product attribution, not a hero/header.

Suggested treatment near the bottom:

`Minerva Technologies`

or

`Powered by Minerva Technologies`

using subdued text, small size, generous spacing, and no heavy black banner.

Do not add another large card or decorative block solely for branding.

## Acceptance direction

1. Large black Minerva Technologies top block is removed.
2. Main registration content moves up and gains usable vertical space.
3. Minerva Technologies remains visible in a subtle bottom attribution.
4. Registration flow/functionality is unchanged.
5. Mobile viewport is specifically reviewed.
6. Accessibility and contrast remain acceptable.
7. No new visual element competes with the registration CTA/form.

This polish must be completed before ENTRY's first real operational launch.
